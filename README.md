# FateMinter

Web3 NFT minting platform built with React, Express, PostgreSQL, and ethers.js. Features Radix UI components, Drizzle ORM, and wallet integration via wagmi/viem.

## Stack

- **Frontend:** React + Vite + TailwindCSS + Radix UI
- **Backend:** Express + PostgreSQL + Drizzle ORM
- **Web3:** ethers.js, wagmi, viem

## Setup

```bash
npm install
npm run dev
```

Requires `DATABASE_URL` environment variable.
